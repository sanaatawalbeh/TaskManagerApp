# Task Management Web Application

Task Management is a full-stack task management web application designed to help users organize, track, and prioritize their daily tasks.  
It provides a clean and intuitive interface, allowing users to add, edit, complete, and delete tasks easily.

---

## 🚀 Project Overview

Task Management aims to provide a simple and efficient task management solution.  
The project follows a modern full-stack architecture using **React** for the frontend and **ASP.NET Core Web API** for the backend, with **SQL Server** as the database.

The system is scalable, structured, and built with best practices to ensure smooth communication between the client and server.

---

## 🛠️ Technologies Used

### **Frontend**

- React.js
- Axios
- React Hooks (useState, useEffect)
- CSS / TailwindCSS

### **Backend**

- ASP.NET Core Web API
- Entity Framework Core
- CORS configured for React
- RESTful API structure

### **Database**

- SQL Server
- EF Core Migrations

---

## 📌 Core Features

- Create new tasks
- Edit existing tasks
- Mark tasks as completed
- Delete tasks
- View all tasks
- Filter tasks by status
- Fully integrated frontend and backend
- Persistent storage using SQL Server
